# 密码安全与数据安全 · 讲义幻灯片

面向 2026“经纬杯”交通运输网络安全大赛决赛 B 组团队赛的概念讲解，基于 [reveal.js](https://github.com/hakimel/reveal.js) 5.2.1，通过 GitHub Pages 发布。

- 在线地址：https://hanami-ume.github.io/
- 字体：思源宋体（Noto Serif SC）、JetBrains Mono（Google Fonts）
- 公式：MathJax 3（reveal.js math 插件）
- 操作：← → 切换章节，↑ ↓ 章节内翻页，Esc 总览，S 讲者备注，F 全屏，Ctrl+Shift+F 搜索
- `labs/`：5 个可选实验的附件包（数据均为教学构造）

目录结构：

```
index.html            幻灯片
assets/deck.css       纯黑主题样式
assets/widgets.js     工具箱、身份证校验器、RPO 计算器
vendor/reveal/        reveal.js 5.2.1（MIT License）
labs/                 实验附件包
```
